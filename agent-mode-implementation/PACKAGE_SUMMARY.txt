🚀 QUICK START
═══════════════════════════════════════════════════════════

1. Install dependencies:
   npm install lucide-vue-next

2. Copy files to your project:
   - components/AgentModeModal.vue
   - components/agent/AccountRetentionResponse.vue
   - components/pendo/PendoIcon.vue

3. Import and use:
   <AgentModeModal 
     :is-open="true"
     title="Agent mode"
     initial-context="How can I help you today?"
   />

4. Test it:
   - Open modal ✓
   - Drag it ✓
   - Send message ✓
   - Close it ✓

⏱️ Time to implement: ~10 minutes

🔧 TROUBLESHOOTING
═══════════════════════════════════════════════════════════

Icons not showing?
  → npm install lucide-vue-next

Modal doesn't open?
  → Check isOpen prop is true
  → Check component is imported

Can't drag?
  → Check for JavaScript errors in console
  → Verify event listeners are attached

Styles look wrong?
  → Ensure CSS variables are defined
  → Check for conflicting global styles

Position is off?
  → Check z-index conflicts
  → Verify fixed positioning works
